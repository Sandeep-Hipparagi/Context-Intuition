## Reporting a Vulnerability

VibeCore implements a strict Zero-Trust Policy Enclave for personal agent systems. If you identify a security vulnerability, bypass of the Tiered Guardrail Enclave, prompt injection vulnerability through browser DOM wrappers, or unauthorized state execution:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately to **Sandeep Hipparagi** via GitHub Security Advisories at [https://github.com/Sandeep-Hipparagi/Context-Intuition/security/advisories/new](https://github.com/Sandeep-Hipparagi/Context-Intuition/security/advisories/new).
3. Include detailed steps to reproduce, affected versions, and potential impact.

We aim to acknowledge reports within 48 hours and release patches in coordination with responsible disclosure practices.
